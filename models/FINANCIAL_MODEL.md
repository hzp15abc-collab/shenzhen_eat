**用途：比较方案的结构性差异、获得现场验证门槛；不是当地流水预测、租赁报价或利润承诺。** 假想于2027年1月开业，逐月至2029年12月，共5类模式×3组情景。所有未获得现场证据的具体假设明确列在 model.py 和 model_results.json 中。价格均人民币，金额以元计算；自然年内逐月模拟开业爬坡、节日/寒暑假相关的消费淡旺季、运营日数、回头客成交、原料人工上涨及竞争分流。

## 3. 沙盘通俗解释和公式

1. 月商业消费机会 = 普通日汇总机会量×开放天数×季节系数。机会是经过/可能购物的商业访次，**不等同于去重人数或学生人数**。
2. 购买订单 = 新客商业机会×新客转化假设 + 回头客商业机会×回头客转化假设。新客率A/B/C/D/E分别7.5%/6%/7.3%/6.6%/7%，回头客机会转化率分别17%/15%/16%/15%/15.5%；回头客机会份额由约8%随开业时间爬坡至43%–47%左右；这不是同一个人的真实复购率。总订单还受日最大出餐容量、爬坡、竞争分流限制，新旧客都按同一比例截断；无重复计量。
3. 月营业额 = 实际订单×加权客单；月毛利 = 营业额−实际含损耗的食材成本。消耗采购额 = 已售食材成本÷(1−损耗率)，逐品类算。
4. 实际贡献 = 毛利−包装−变动支付/平台/推广预留−共享分成−税费预算。贡献不是毛利，亦非净利润。维护设备另按营收0.6%预留；若大量外卖，需另建按渠道计费模型，不直接套用此系数。
5. 业主计薪后经营利润 = 贡献−月租金−物业−雇员工本−业主机会人工−水电杂费及固定推广。若经营者不领工资，可暂留现金，但不能将无偿劳动错算成资本盈利。
6. 会计近似利润 = 上述经营利润−折旧摊销（装修36月、设备60月、转让费36月）；这是分析账非税务账。
7. 月经营自由现金流 = 业主计薪后经营利润−库存资金变动−设备维护资本支出。店铺在第0月投入装修设备等与押金、库存，储备金留下应对现金亏损。每月现金 = 上月现金+经营自由现金流。
8. 回本 = 累计经营自由现金流覆盖第0月启动支出（不含尚在账上的备用金）；同时记录更严格的覆盖全部融资口径。若现金耗尽不追加资金，现实中可能先停业，36月情景只是“硬撑继续”的反事实压力测试。
9. 退出损失 = 第0月启动支出−累计自由现金流−退出净回收额（假设押金回收60%，设备按期间折价，存货回收50%，扣1个月租金、半月雇员成本、800元杂费）。退出合同、违约、债务、食品不可回收、员工赔偿等可能更严峻，此不是最大亏损上限。
10. 资本机会成本：用年折现率6%作测试门槛（并非融资报价）；净现值=全额融资初始投入负值+逐月折现自由现金流+期末折现的备用金及假设清算回收额。

## 6. 如何把模拟变成真实生意决策

- 先取证：按社区商业节点现场做7天汇总客流观察（不辨认、追踪个人），取得经营证照/租约与3家供货商报价。记录通用餐饮顾客成交数、成人问卷、订单金额、产品损耗以及单客交易结构。
- 用真实成本替代租金、水电、分成与人手，拿供应商报价成本复算每个SKU。
- 如许可和合同允许，先验证轻量菜单、预售或合作时段。设定两周内每日成交量、贡献率、售完/报损、排队时间与实际可排班工时的检验，不以最低工资和未核定租金作为承诺。
- 每次扩店或增加班次只比较**增量**贡献与新增租金、设备、人力、合规成本。不能用全天门店营业额替代独立早餐店利润。
- 合同未签前锁定退出条款和最大可承受亏损。举例：若连续4周正常营业时订单与实际单位贡献仍不能覆盖固定成本，应更新沙盘、缩减菜单/班次或重新谈判，不能盲目充值；具体停损阈值由经营者预算和实际合同决定。
- 根据销售、成本、竞争动态每周更新输入，再跑同一脚本。若出现新增平台费、非均匀时段动线、原料供货限制，则细化到产品/班次/渠道模型后重新核算。
  
## 7. 可复算文件和验收

python3 model.py（标准库即可，不使用网络）生成：
- model_results.json：完整模式、场景、季节、参数、汇总、敏感度。
- monthly.csv：15情景×36月份=540行，逐月订单、收入、材料损耗、包装、成本、利润、营运资金、现金流、退出盈亏。
