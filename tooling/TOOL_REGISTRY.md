## 2. 具体记录
- **Web（房产）**：搜索“深圳 宝安 福海 新和社区 早餐 商铺 出租 餐饮”。安居客索引的多页重复广告：宝安福海街道桥和路66号餐饮早餐凉拌菜旺铺转让，30㎡，报价8860元/月（约9.84元/㎡/日），转让费面议。地址非项目核心区，挂牌非成交，网页索引上个月。来源 https://sz.sydc.anjuke.com/sp-zu/baoan-qiaots-hy9-px2-pv1/ 。只作一个同街道比照样本。
- **Exa（商户）**：聚合检索一次返回10条候选，范围较大，不是新和社区精确商户数量；其中传统早餐、砂锅粥、湘菜有当地命名线索。来源 https://exa.ai/library/places?ids=8mv2tmnsk6r%2Ccdhvrvm6lqq%2Cktz7tnqvz41%2C1w23kjr350m%2Cbdbl5n8fqj2%2Cvsn67nszztt%2C0sbphvbqmff%2Cx36z7640cff%2C0y80gwnf2jz%2Clwdpjsftxm7 。不把聚合记录的“open”当当日营业确认。
- **Exa→原站**：由语义搜索获得品牌原站，再直接打开并查找“福永新和店”。官网列该门店为福海街道新和社区二区一巷5号悦康路5号。原站 https://www.alittle-tea.com/storelocations/1/20/198/1783/ （访问当日可读）。可确认品牌官网列有该门店，营业时段、客单价、当日运营未核实。这个结果演示“发现→直证”流程。
- **58**：Exa索引显示新和二区悦盛三路6-3号附近一份100㎡、1万元/月的餐饮挂牌；尝试原页 https://sz.58.com/shangpucz/ 返回验证码。仅保留陈述“检索摘要存在此广告”；不能确认当前状态、押金及转让金。另一转铺网线索 https://sz.shangpu5.com/zhuanrang/show-14168.html 显示桥新路98㎡、月租9500元、转让费20万元，发布日期未显示；卖方自述盈利不当作事实。

## 3. 输出工具实测
本地 Python 包探测：ReportLab、matplotlib、pandas、numpy、PyMuPDF(fitz)、openpyxl 已安装，WeasyPrint 尚未安装；Poppler的 pdfinfo、pdftoppm 可用。字体存在 Noto Sans/Serif CJK。实际创建一页 ReportLab 中文概念样张并用 PyMuPDF 提取和渲染，能读出两行中文，无乱码（样张为临时实验，并非最终版）。结论：采用现有 Python + ReportLab + 计算生成的图表 + PDF渲染独立复核；没有必要额外安装 WeasyPrint 或使用陌生项目模板。最终版字体嵌入、各页渲染和排版仍需单独验收。

## 4. 数据等级
A = 官方/原始文件且数据口径清晰；B = 可回查商业平台挂牌或品牌名录（仅证明其公开陈述）；C = 搜索摘要、商家宣传或间接估算；U = 无证据，必须验证。A级人口统计也不能代替某条商业街的实测客流。样本少时不报平均值、市场占有率或排名；食品热销、餐饮销售和投资回报一律以现场或模型条件呈现。
