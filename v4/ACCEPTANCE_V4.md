# V4 目标验收门（不可用页数/断言数量代替）
1. 原始用户需求逐项 → 证据、具体成品页/图、模型位置 → 实际状态；局限不包装为完成；本地能力必须真正测试。
2. 真实调研增量：地区线上可取得有日期/来源的店名、餐品/价格、铺段及挂牌、招聘/供应成本、外卖费/履约证据；所有缺口按证据等级诚实列出。工具不足回选择模块，用实际试验记录，而非只抄网站介绍。不冒充当地实测或登录，不绕过验证。全部未获取本地合同标为未知。
3. 前台先展示地段/客群/竞争/产品及场景，再比较五模式、两人能力与平均/峰值产能、设备/装修/库存/外卖/租赁的开办账，完整因果链从订单到现金及停业。各模式的产品、场景（含跨时段共享）、投入/工序/人员、推导、退出均可浏览，不重复11页同模板。
4. 读者结论在前、解释在后；金额人民币直接表达，实际开业付款与留存/净利润与现金/分配与回本/退出当天与终局损失必须分清；每模式至少一个完整、可追溯的可视化推导；五模式对照、三投入/三渠道/三需求财务结果归档，可互动查看。
5. 视觉实物对比：预先制作候选样板组，至少覆盖真实商业街景＋区域关系、菜单竞争、完整资金到利润/现金链、退出及跨模式比较。V2/V3对同题作为基线，不以样稿本身得分代替实质改善。独立审稿评分阅读30、逻辑20、视觉20、准确20、移动10；无伪实景、错误金额、标题、读者核心问题无法回答属于硬失败。图文内容以读者理解为主，不凑页数，不仅是卡片/条形图。
6. 整份原生手机单栏，360/390/430实际渲染；至少关键页真实视觉比较，文本可提取、导航有效、金额匹配；自然文案、真实照片/示意许可/来源明确，并保留可编辑模型和研究。独立审稿不是用户实际测试。
7. 总目标监督逐项比较，不通过返回工具/研究/经营/财务/设计对应模块；记录实际修改、复验，确保真实结果与最终成品相符。
