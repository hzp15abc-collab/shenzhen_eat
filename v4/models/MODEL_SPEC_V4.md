# V4 财务模型说明：让读者看到从每一单到两个人实际拿到的钱

**2026-11-27；金额均人民币元；模型是条件沙盘，不是新和实际门店营业账。** 两位合伙人工作但工资为0，新增人员按完整雇主预算和共享产能匹配。V3经过独立校验的135主情景、4860个月度和540个四时点退出结果保留不改，V4不是为了抬高或压低投资额任意改参数。保留的数据不代表完成全部本地实测。

## 1. 为何 V4 没有直接把新的挂牌/单品价代入全商圈
具体铺面、装修套件、两平台店内费率和真实顾客订单没有签约、成交或同口径完整证据。直接拿一个30㎡上下铺面、装修齐全的挂牌当所有早餐店平均真实投入会误导；将品牌自提一件商品当整单全部到店/外卖消费也一样。V4新增可追溯的、其他参数暂保持的**条件替代/敏感度**；没有足够同一门店运营数据就不假装校准。参见 [证据如何进模型的逐条决策](../evidence/finance_evidence_decisions.json)，新增原始市场、产品、物业用工和外卖调研在V4研究及证据目录。

## 2. 前台的真实算账链

每模式只需按同一条以下因果链读，报表精确字段都可追溯：
1. 需要准备的钱 = **开业前已付/占用**（装修、设备、转让、押金、库存、开业和外卖准备）＋**仍在账户**的三个月固定支出储备。押金库存是占用，非营业费用。每项列数量与单价，核实可复用资产才扣去重复；开业首月房租在经营月结账，仍需真实租期押付确认。
2. 可购买机会 × 购买转化/复购互斥池 × 开业爬坡 × 季节 × 竞争 → 潜在日单。两个渠道共用厨房，先按渠道需求，再用双方全天人分钟、高峰人分钟和设备能力三个约束取最小结果。每班用时是设计待实测，不是孩子时间或人流；无实测潜在单或客流不能写成事实。
3. 现场、两个平台逐单：标价 − 店方优惠 − 预计退款 = **货品净收入**；净收入 − 食材实际消耗/损耗 − 包装 − 技术/履约 − 支付费用 − 共享分成 − 税费预算 = **一单贡献**。税费1.5%是风险预算，不是法定税率。顾客付的配送费不当商户收入；平台补贴不虚构。月订单=各渠道日单×当月经营天数。
4. 成熟第12月净收入 − 可变经营支出 − 房租/物业/水电/营销/其它/受雇员工费用 − 人员调整费用 = **经营结余**。这不是实际提款；近似会计利润还减摊销（非税法认定）。日均固定支出是按当月开门天数平摊；按每单贡献计算正常固定支出保本门槛。
5. 经营结余 − 库存资金变动 − 未到账的外卖款变动 − 设备维护支出 = **经营现金净流量**。期初账户 + 经营现金流 + 必要追加资本 − 实际模拟分给合伙人的钱 = 期末现金。三个月储备按首月固定费用估算，非保证。50/50只是分配演示；每季度对储备超额按50%分，若累计注资则停止分配；不能将未分配的经营结余说成老板拿到手。
6. 回本两种口径：累计经营现金流首次覆盖初始支付/占用、首次覆盖全部初始筹资加补资。都不是实际全额分红到账。另列款项累计分配、账户余额、两人平均每人工作时间，为用户理解投入人的代价。**实际分配/工作小时仅为现金分配的时间强度诊断，不是工资、时薪标准、保证收入或新的成本扣减。**
7. 退出：当时账户现金+资产回收−退租结清等费用，得退出净返回/净补资；若回收未到账先付后收需过桥。累计两人损失=开业全部筹资+后来追加+退出净补−已经分配−关店拿回。不再把经营亏损另加一次。损失为负代表净收益。设备/库存/押金残值和合同损失皆为假设，不代表真实法律赔偿。对实际合同到期不续的条件方案另去除提前退租租金项，其他回收和退场费用仍是假设。

## 3. 实际调整与方法修复
- 单因素价格纠错：V3“线下售价低10%”在变更基准价时无意使按基准价计算的食材绝对成本也下降，低估了价格压力；V4五组单因素重新运行，固定每份人民币食材原成本；标准135主情景未受影响。新旧差异写入 sensitivity_corrections 字段。线上增量场景由原标签改成“潜在总订单新增20%（均为线上，线下不减少）”，即原25%线上至45%、线下75%保持，与线上量增加20%不同。
- 11个新增证据关联条件：两个A租约挂牌、A盘点证实2万复用、A烟道全换8千/1.2万替换旧5千；D真实76㎡挂牌两项替代及食堂竞争三项测试；E场地7千/整租1.3万两项风险。租约到期不续另算退出，不承诺广告仍有效，不以假设续租证明可回36月投入。
- 30个新平台差异单因素：对每种模式逐一增加美团或淘宝一方配送2元/交易费3个百分点/店方券5个百分点，其他条件相同并重新选择雇员及现金流。两者基准参数相等只是无证据的同条件比较；平台保证金基准不同也仅为测试。共享E合法许可/场地及平台审核未证实，故全部E仍是条件可行性，不能据数字直接营业。
- 新增按每人每年及三年实际工作小时计算经营结余强度与现金分配强度，老板仍为零工资费用。D需具备热厨及多时段轮班能力；若需另外聘厨师，V3 5个专技重算保留，不把老板当无限人力。

## 5. 文件、复算与证据链
- report_data_v4.json 是 V3 原数据及新增 reader A–E、conditional_tests、platform_asymmetry_tests、sensitivity_corrections、v4_meta；只有54项旧敏感性中5项数值修复、5项文字澄清，其他母表保持完全一致。
- reader_finance_v4.json 为面向报告的精简提取。各模式 opening.categories 有逐项开办清单、capacity 有人/设备/忙时限额、month12 有三渠道单位成本和全部月度收入/开支/现金链、years 有年度与36月序列、exit与weak_exits 有四清算时间、comparisons 有各三档投资/渠道/市场情景同口径截面。
- conditional_finance_v4.csv、platform_asymmetry_v4.csv、sensitivity_v4.csv、sensitivity_corrections_v4.csv 是新增量便于Excel/CSV筛选（原始精度JSON，CSV只输出合理精度）。
- 运行 python v4/models/build_finance_v4.py 读取冻结V3源模型及文件，再计算V4条件，不写入V3。运行 python v4/models/validate_finance_v4.py 独立从CSV/JSON验证135、4860、540不变及资金/每单/营运/退出、容量、条件敏感性恒等式。输出为 FINANCE_VALIDATION_V4.txt、INDEPENDENT_ARITHMETIC_V4.txt，另外有独立总目标监督Agent检验。全部不是现场店测，也不是外卖合同获取成果。
