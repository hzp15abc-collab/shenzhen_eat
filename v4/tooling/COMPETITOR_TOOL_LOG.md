# V4 竞争资料工具实验和回退（实测）
2026-11-27；目标是核心新和社区公开可核地址、商品、价格、图像；优先直接原始源。严禁把索引、自述、图像、监管样品当实时销量。

| 渠道及测试 | 实际结果 | 回退与使用边界 |
|---|---|---|
| 百度地图Agent Plan技能 | 阅读能力须配置BAIDU_MAP_AUTH_TOKEN；环境变量为空；OpenCLI命令不在PATH | 未发送API请求，不能宣称POI API实测；不索要凭证；改公开网页 |
| 标准Web精确检索 | 新和三区、二区、工业园、店名、菜单、食品抽检；政府抽检公告、城巿吧索引和挂牌可得。市监xlsx在搜索工具click显示unsupported content type | 从官方公开链接实际合法curl下载，Python逐行解析 |
| Exa网页检索/读取 | 提供确切KFC、必胜客独立价页及新和周边咖啡目录、和平夜市新闻。Exa地点聚合多为旧线索，未据其open字段认当前营业。City8正文获取超时 | 精确筛选、拒绝泛化AI内容；对价页直接HTTP获取实际新菜单 |
| Firecrawl三个本地关键词实验 | 一组无网页结果；另外7/15个结果主要为泛深圳酒店、无关目录，无法取实际本地新和独立店菜单 | 不采；回到政府和第三方实读页 |
| 国家企业/招工公示搜索 | 食品经营者名称及餐饮招聘记录线索，与实际在营/菜单不能等同 | 不采集联系人、个人号码或与公开商户无关的个人信息 |
| 官方市场监督管理局原始文件突破 | 13份公告附件直接合法下载200、读取72,700条，筛地址及排除校园后137条、32主体，保留行号、链接、SHA；附工作脚本 | 来源一手，仍只证明商品/主体当时记录；不做当前密度或销量 |
| Drive Thru Index直接公共HTTP | KFC桥新路（本地）83项、必胜客桥头98项，正文采价2026-11-26。旧索引74/95项及日期不同，实际读取正文优先 | 184价CSV含旧越师傅3项，分别标本地/邻区/来源，不能直接算客单和配送价 |
| 大众点评/美团/淘宝平台 | 对新和、具体店名、关键词公开搜索无足以当作真实本地菜单的入口；无授权当地消费/商家会话 | 不绕过，不宣称抓取；用户App/商家签约记录为后续实证 |
| Commons公开搜索/地理照片检索 | 精确找到2026新和公交总站；Wikimedia公共API以商区交通点附近检索出福永海鲜市场2026等、相邻真实照片。逐张核extent许可元数据并实际下载/观察内容，挑8张新图 | 禁止伪称全为新和三区当日图。CC0及CC-BY-SA4.0，保留作者、许可证、来源、日期、SHA、地理范围。政府/商家相片许可未核，仅链接 |
| 地段挂牌补充 | 完整实读新和五区35㎡ 2660元/月+3万转让；新区三区60㎡ 2580/月、邻步零食60㎡ 7500/月仅索引 | 交成本agent去重；不是成交/实时可租，未披露费用不能为零 |

## 复现
同一环境执行 python v4/tooling/extract_regulatory_samples.py（公开政务附件动态会更新；冻结版本附SHA）、python v4/tooling/extract_pickup_menu.py（动态菜单可能变化；冻结版本SKU及时间见CSV）、python v4/tooling/build_competitors_v4.py。官方附件未整份入库，只保留新和非校园实体样本/定位证据及来源，防止将无关地区、个人、校园数据传播。下载的图像见资产清单，所选图片版权许可明确。
