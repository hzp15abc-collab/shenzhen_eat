# V4 离线情景导航（报告伴读）

## 使用

打开 `deliverables/Shenzhen_Eat_情景模拟_V4.html`；Mac 双击或浏览器“打开文件”，手机在支持执行本地 HTML / JavaScript 的普通浏览器打开。部分聊天应用或文件预览只显示静态页面，改用浏览器。全数据、脚本、CSS、5种模式代表照片均内嵌，不需联网、安装第三方库、服务器、账号或外部资源；原始证据和摄影出处为可选点击链接，默认不发网络请求。不发布网站。正式交付仍以手机PDF为主，HTML用于自行切换和查账。

## 真正改变的阅读方式

- 首屏从以前四张孤立的结果卡变成每模式真实同类/周边历史照片＋两位老板岗位分工＋从头到尾的7步现金链：开业备款、该做多少单、真实扣除商家券与退款后的净销售、扣订单变动成本后的贡献、扣固定支出后的经营结余、净现金流、半年退出累计净损失。照片不冒充目标门店，作者、许可、日期、图源透明；E照片只是福海同泰广场小吃摊位参照，并非共享合同线索。
- 所有135组合仍可由模式5×档位3×渠道3×需求3切换。后面明细展开资金去向和备用金、需求及全天/高峰/设备约束、到店/美团/淘宝闪购每单、月费用和现金、36月现金账及回本、四时点退出、每人分配和追加。两位合伙人不发工资。不是推荐排名，五五仅为计算示例；没有测得真实当地收入、渠道费率、订单。
- 颜色和布局继承V4同题已选方案的深蓝灰/温纸、橙色说明扣款或风险条件、青绿正现金、红色风险；首页大图加连续编号链。手机单栏、桌面适应两列；原生下拉/链接/详情及表格，按钮最小44px，焦点可见，移动表格仅在表格容器内水平滚动。实际上未进行浏览器像素测量，不能用CSS意图代替视口实测。

## V4新增有来源的独立条件

面板07位于退出清算之后，**全部以标准投入＋混合渠道＋基准需求为可比基准**。不会暗中改变135档模型或叠加独立测试，也不会让当前档位/需求开关误解成这些特殊测试的入参。

- 11项 `conditional_tests`：A新和32㎡米粉挂牌（月租3040元、转让4.2万、剩7个月）、新福工业园25㎡早餐挂牌及附条件核实2万元可复用、排烟加建；D福园一路76㎡快餐、同街道企业食堂替代价格压力/需求压力；E分时共享场地成本升7000、极端承担整租13000情景。每条显示公开事实、来源链接、证据层级/假设、标准与测试筹款/年均结余、第12月经营结余/保本、半年净损失、影响。短租期显示正常到期退出清算及续约反事实，不承诺续租；报价不等于成交，商家收益与客流未核。一些模式没有独立挂牌测试时明确提示，不套其他业态。
- 30项 `platform_asymmetry_tests`：分别对单个平台调配送费、技术费、商家优惠率；现有双平台同费率是合同未知时的假设，不代表平台相同或哪家更贵。
- 五模式修正后的单因素降价压力：旧算法意外带动绝对原料成本下降，V4保持原料绝对成本、更新5条“线下售价低10%”结果，展示旧值错误与修正后值、差额；其他基线未变。全部54条压力测试可按模式展开。
- 决策底稿保留V4新增事实和为何不硬改基准；实际本地菜单证据为第三方自提App观察或可核价格个案，并非美团、淘宝闪购真实商家结算；共享档需合法场地协议、主体许可和平台核验。

## 数据和复算

取 `v4/models/report_data_v4.json` 冻结法（SHA256 6a37b3688833af22a7950fe44a6b94ab88a82a13185859da4dc583f4ea0a5834）和 `reader_finance_v4.json`（SHA256 160134f6833cb0ddfdc8963ff864e8e873b9249c0a7be9895010063cff1e43c0），构建时二者 reader/测试逐项比较完全一致；V4主canonical 135个组合与V3相同，仍使用可复算的 `v3/models/monthly_v3.csv` 全量M12逐笔字段与月度核验。嵌入三个源文件哈希在页面底部，计算精度保存到1e-6元，页面以元/万元及逐单两位取整。取整分项可能差1元，以未舍入计算为准。

构建和验证：
```sh

node v4/design/test_explorer_v4_node.js
python3 v4/design/test_explorer_v4.py
```

生成器需Python与Pillow用于嵌入图片；生成的单文件无需外部依赖。模型如更新，先重新生成冻结文件，再运行HTML构建与测试；禁止手改页面显示还宣称匹配模型。
