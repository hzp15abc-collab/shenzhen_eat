# V3 最终版设计说明

正式题名：深圳宝安福海新和社区早餐与休闲零食市场调研及商业可行性分析报告。
- 手机长页：390×844pt、单栏、一页一问题，目录、模式导航及页底返回链接，非电脑A4缩印。
- 三种同内容实际样稿：A街坊纪实、B财经图解、C决策笔记；独立评审为90 / 94 / 92。最终融合B的财务拆解、A的照片与暖色、C的读者口语。
- 全报告96页：从五种方式总览、商圈、成本与经营规则，进入每模式11页（产品与规模、资金、档位、订单、单笔成本、月利润、现金、回本、分配、退出、四时点退场），再做弱/中/好市场、渠道、师傅与竞争压力测试。
- 真实邻近历史街景和同类产品照片，清楚标地点、年份、摄影者、授权和原始链接；无AI冒充照片；来源附录和完整资产清单。
- 仅从冻结模型数据取数，指标直接用人民币元/万元，亏损红色、回收降低损失绿色；面积、租金、职工费、回本、退出均以条件场景呈现。
- 实际渲染自迭代：初张检查发现孤字标题、退出色彩方向、三栏负金额挤出；修正标题测量、退出桥颜色、金额自动字号，复验手机画面。每份样稿和正式报告都实际生成；禁止以设计意向代替实物。
- 报告只用公开证据及明确情景，真实线下客流、实时外卖菜单、具体商户流水与合同尚未取得。不以图片或网页目录推测门店真实利润。
- 生成人：`python v3/design/build_report_v3.py`，需要 PyMuPDF、Pillow、fontTools 与 Noto Sans/Serif CJK字体，代码从Linux系统字体取SC子字体；Mac上需修改字体目录或准备同名TTC文件（见pdf_engine.py）。生成手机PDF及页索引。冻结参数与CSV文件见models。
