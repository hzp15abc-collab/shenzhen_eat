# V3 手机商业调研报告：信息设计与自然表达选型

**日期：2026-11-27 · 状态：完成实物样稿比较，供总控与最终独立验收。** V3不是让上一版表格换个颜色，而是把商业问题变成普通读者可以自己复核的推导链。先讲场景，再讲钱如何算，最后讲什么情况下会亏；不替投资者作决定。

## 1 ｜调研与可复用的原则

以下是本轮确实检索、打开或查验的可访问参考。仅借鉴信息表达和方法，绝不把国外经营统计或教程数字套进深圳的店铺模型。只看到落地页/可检索正文的资源均注明，未宣称看过付费内页或未取得的视觉稿。

本轮也比较了当前已有的解释性写作、商业报告和数据可视化方法，以及 V2 时已通过实际 PDF 生成测试的 PyMuPDF。PDF 采用可选中原生中文文字和矢量图，而非纯图片整页。选型原则是**模型与图表必须能受同一个数据契约支持**；如数据发生变化，重新渲染原型、而不是更新静态结论。

## 2 ｜ 三套同数据原型：真的生成再评审

原型均为3页（结论总览、每单如何变成月度账、退出怎么算），统一的假设与内容如下；它们与最终调研财务模型无关，所有页均标明是例子。

- 18.8万元启动资金：装修4.5万、设备2.8万、转让费4.2万、押金1万、备货0.6万、外卖开通0.2万、杂费0.5万、备用金5万。
- 每日潜在订单180，假设两位合伙人的产能160，实际接160；线下100单、外卖60单。线下每单9元减食材3.2、包装0.5、支付等0.2＝5.1元；外卖每单商品价14减商家优惠2、平台配送3、食材4、包装1.2、其他比例费0.3＝3.5元。每日720元×27营业日＝19440元，扣除租金5000元、水电2000元、其他固定开支2800元，示例月经营结余9640元。两位合伙人无工资，例中没有员工。
- 开了6个月后假设退出，不是正常月利润情景。初投18.8万＋追加1万＝19.8万；账上4.2万（初始5万＋追加1万－累计经营亏损1.8万，累计亏损已计入不可再扣一遍）＋回收设备/押金/库存2.2万－清场与结账费0.9万＝回收现金5.5万；不曾分红，最终损失14.3万；各半出资假设每人7.15万。另假设当天账上钱可支付清场费，本例当天不用另筹钱。真实项目会有具体负债、回收时滞等变化。

| 候选 | 视觉方式 | 主要优点 | 实物观察的代价 |
|---|---|---|---|
| A 街坊纪实 | 暖米色与街景→数字摘要→费用表；退出用逐项扣减清单 | 亲切，第一眼清楚出资规模 | 费用占比要读表，退出没表现累加轨迹 |
| B 财经图解 | 简单冷色系；启动资金比例条，单笔成本构成条，退出损失瀑布桥 | 每一层金额如何形成最清楚；便于对照多个经营模型 | 地方文化气息偏弱，瀑布图首次读需先理解标注 |
| C 店主决策笔记 | 卡片提问题→箭头→回答；收据形式与退出三段算式 | 最自然、最像实际向店主解释，退出算式易心算 | 财务费用缺少比例视觉，比较不同模型时不如B紧凑 |

## 3 ｜ 正式报告逐层表达合同

### 首屏和目录

报告标题使用“深圳市宝安区福海街道｜新和片区早餐与零食市场调研报告”（在地理证据确认后再最终定名），不要变成“开一家小店”的预设结论。打开报告先看到“这附近是谁在消费／有哪些不同做法／各自投入及风险多少／哪些事还不能确定”。每个章节顶部一句自然语言结论和两三项关键数值；可点击目录、返总览、来源附录。开店、金融及研究术语第一次出现时顺手解释，例如“周转金：手头必须留着、不能全部花在装修上的钱”。

### 每种经营模式用一致的推导顺序

| 普通人的问题 | 图形/表达 | 必须输入和呈现 |
|---|---|---|
| 这是什么店？ | 模式卡，真实邻近参照图（明确地点）或矢量工位示意 | 经营时段、产品、容量/面积、模式、两合伙人和必要雇员 |
| 人从哪里来，能卖几单？ | 有标签的竖向漏斗或双路径，再收束至订单上限 | 按群体和时段曝光/转化、回头客单量去重、单量受工位及高峰产能限制；不能对未实测客流伪精确；把需求与实际接得住的量区分 |
| 每卖一单剩几块？ | 线下/外卖分组成本条，3–6项扣减标上金额 | 商品价、商家优惠、食材、包装、支付费、适用平台、配送、促销和退款；区分顾客配送费和店主实际承担，防重计 |
| 开店前现金花在哪里？ | 启动资金组成色条+可直接复核的短标注 | 租金押付/押金/转让、装修、设备、证照、首批货、开通/宣传、流动资金；分清已支出、可退回和手头备用金 |
| 一个月能剩多少？ | 每单×日单量×营业日→固定开支与必要雇员→经营结余瀑布 | 两位合伙人工资均为0；按规模及能力核算雇员实际用工成本；线下和外卖分别计算、固定和总变动支出分开，解释“经营结余≠净利润≠可以直接分掉的钱”；明确折旧/税费/维护/预备金处理 |
| 订单降到多少开始亏？ | 保本标线，淡旺季对照，加权渠道贡献与产能边界 | 月固定开支÷加权单均贡献，转换到日单量；与产能上限对照；销量非唯一因素，敏感性加入价格、平台费、租金、人工、原料与损耗 |
| 如果持续做3年？ | 三条36个月走势、小型关键期卡片、经营现金与累计回款清楚区分 | 淡旺季、寒暑假、爬坡与复购、竞争分流、招人扩容、额外投入、回款时差、现金底线、分红与回本条件 |
| 要是做不下去呢？ | 退出损失瀑布+三段账：投入了多少／能拿回多少／真正亏多少 | 退出时点（3/6/12等）、资本追加、已分红、账上现金、押金/设备/存货回收率、平台未结款、违约/清场/欠付，现金回收时滞；经济损失=累计净投入－退出净现金价值，切勿将已从现金扣掉的经营亏损重复计入；另列退出当天要筹现金与最终净损失 |

在每个模型结尾用 2–4 条条件式“如果……，数字就会……”和证据缺口，不用无来源的风险分数代替解释。退出图建议额外给合伙人按实际出资比例分担，但只在比例明确或明示假设时展示，且不要假设所有责任一定有限。

### 语言变得自然，并且数字更直观

| 避免 | 推荐 |
|---|---|
| “外卖渠道边际贡献 3.50，门店渠道贡献 5.10” | “同一份订单，堂食或自取最后能留下5.1元；外卖虽然卖得更贵，却只留下3.5元。”后面紧跟扣费组成。 |
| “固定成本 9800/期，Q=61.5” | “每月不开单也要花9,800元；到底要卖几单才打平？用9,800元除以每单平均留下的钱，再按营业天数算。”展示真实计算。 |
| “投入 CAPEX 188000；流动性50000” | “开店前共要准备18.8万元，其中5万元先留在账上，不能都花在装修和设备上。” |
| “极端场景退出投资损失 14.30w” | “两人合计投入19.8万元，如果退出只能净拿回5.5万元，那么最终亏14.3万元。” |
| “学校客源占比 60%” （没有实测） | “学生是潜在客群之一，学校就餐和家长接送会影响这一比例。当前没有可信的校门统计，暂以低至高情景演算；需要工作日现场计数才能确定。” |

元与万元按阅读习惯选取：较大金额如18.8万元，单笔成本用3.5元，每月收入用9,640元或1.2万元；不使用`18.800万`、`1.20w`、`0.000064百万`等数据表式精度，四舍五入不修改底层金额。按语义仅保留必要小数，对不确定的租金/客流/工资做区间并标注时间、口径、来源，不将估计的个位数当作精确调查。

原型唯一照片使用 V2 已取得的邻近许可素材：`../../v2/assets/qiaohe_street.jpg`。查阅 `v2/assets/PHOTO_MANIFEST.json` P01，2023-08-31，福海桥和路，作者 JMUAIANWNC 3366688，CC BY-SA 4.0。截图下方直接显示作者、许可和裁切标记，并可点击原图链接。该图作裁切和缩放，非新和三区实景，页上已直接注明边界。正式报告优先真实商圈/店面（遵守可再用许可及隐私，不追踪未成年个体）；邻近、旧照片清楚标注。缺少证据时宁可用准确的原创示意图，并明示为示意，不能让生成图冒充门店调查或给读者“这是真实店铺”的错觉。图像功能优先解释经营空间、产品组合、工位、采购和出餐流程，而非泛商业摆拍。

## 5 ｜自迭代验收门

1. **证据门**：大数字在底层证据表中有记录，来源标明地点、日期、口径，或清楚标记情景/假设；实拍图不得混为选址证据。
2. **算术门**：对每类模式重算启动、渠道贡献、按产能接单、月支出、长期现金、亏损与退出，核对每个图中金额与同一个数据源，避免跨图合计不符；不得隐藏雇员成本。
3. **阅读门**：由未参与设计的人在390px预览中回答“多少钱开始、一单剩多少、日保本多少、最坏退出亏多少、结果是不是实测”，并追踪图中推导。关键问题都需可回答才能通过。由于目前是自评，不冒充已做用户盲测。
