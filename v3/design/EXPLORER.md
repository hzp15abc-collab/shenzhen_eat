# V3 离线情景模拟器（报告伴读）

打开 `deliverables/Shenzhen_Eat_情景模拟_V3.html` 即可使用。单一 HTML，内嵌 135 种组合数据和脚本，无需安装、联网、服务器、账号或外部依赖。手机可用浏览器打开，Mac 双击即可；部分文件预览程序不执行 JavaScript，应改用普通浏览器。它不是正式手机 PDF 的替代品，而是允许读者自行切换经营设定、复算条件的附加工具。

## 设计

- 先选择经营模式、投入规模、销售渠道和需求强弱；首屏看备款、日订单、月经营结余、六个月退出损益四个核心数字。
- 「开业前」图示资金去向，并区分实际支付/占用、未支用的现金储备、两位各自起步备款。
- 「第12个月」以需求漏斗、日保本比较条、两人及新增员工产能说明订单不是实际客流；把相同时间的到店、美团、淘宝闪购逐单推导并列为可切换渠道明细。
- 「开店一个月」从标价、折扣与退款、每单变动成本、经营贡献、固定成本一路扣减到经营结余，再区分现金流、利润与可分配金额。
- 「三年」曲线与按年卡片展示经营现金流、店里留存现金、追加投资、回本口径、各自平均分配；可展开36个月的逐月账。
- 「退出」可切换第3/6/12/24个月，明确初始资金、追加投资、已分配金额、退出净补款、最终返回现金；另列资产回收和短期垫资，而非重复计为终局损失。
- 使用暖白、深绿、砂色及蓝色图表，红色配合文字标识亏损。手机为单列内容；控件目标至少44px，标签、ARIA选中状态、原生下拉框、表格标题、SVG文字替代描述与键盘焦点均提供；三年明细可水平滑动，其他部分响应式重排。

## 数据及口径

数据取自 `v3/models/report_data_v3.json` 和 `monthly_v3.csv` 第12个月完整字段，生成时核对135个配置、4860个月、540个退出和每月两位合伙人（第12月工资0）、资金与退出恒等式。页面末尾可展开SHA-256，匹配实际研究附件；金额展示取整（万元保留两位、逐单保留两位人民币），逻辑保留精确值到1e-6元，且0元和“不适用”有别。全部模拟是假设、不是经营实测、成功概率或损失上限。平台未开启的情景照样可切换查看虚拟单笔账，但明确该渠道没有产生销售；未确认真实商家费用，不将示例结算等同合同。两人50/50仅用于展示。

## 构建和自检

从项目根目录运行：

```sh
python3 v3/design/build_explorer.py
node v3/design/test_explorer_node.js
```

本轮实际 Node JS 运行测试通过：135/135情景、405/405渠道切换、540/540关店时点切换，源数据哈希一致、输出与原始数值一致、无 NaN 或 undefined 或 Infinity，无外部资源调用。用测试DOM执行真实页面脚本及选择事件；这不是浏览器视口或像素验证。

浏览器复测脚本 `python3 v3/design/test_explorer.py`（需要有效的 Playwright Chromium，可设 `EXPLORER_CHROME` 指定真实路径）。本轮 Linux 环境的 Chromium 包装器存在，但实际浏览器二进制未安装；因此浏览器测试返回 SKIP，并没有声称360/390/430宽度在真实浏览器完成验收。Mac本地可复测，脚本会检查135情景的页面滚动宽度、内容、JS错误、外部请求以及代表性360/390/430/1024像素截图。

在生成器更新后，先重新运行财务模型（如更改模型输入），再重新构建和测试HTML，不手工改动内嵌金额。最终数字以模型CSV和JSON为准。
