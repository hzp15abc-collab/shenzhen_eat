# 在 MacBook Codex 本地接手现场数据增强

当前聊天已在 Mac 客户端使用，但本次实际执行只连接远程 Linux 桌面和云浏览器，不能读取 Mac 上已安装的技能/应用、OpenCLI、Safari/Chrome 登录状态或本机文件。没有调用本机的授权连接，所以不请求无意义登录。本轮使用公开搜索、官方规则及可读取挂牌详情交付完整情境模型。

如果转到具有本机工作区和真实浏览器连接的 Codex 项目，使用原仓库 https://github.com/hzp15abc-collab/shenzhen_eat 并从 AGENTS.md、GOALS.md、WORKFLOW.md、ACCEPTANCE.md、v3/PROJECT_HOME.md 继续。先检查本地实际能力：系统/工作区、现有技能、OpenCLI命令、网页连接可用性；不凭安装列表假定已成功。OpenCLI browser bridge 官方文档：https://opencli.info/docs/guide/browser-bridge.html 。连接需真实浏览器扩展/桥接状态，不能借云浏览器假装本机。

下一轮补证优先级：
1. 正常授权查询大众点评、美团外卖、淘宝闪购及支付宝归属入口的当地餐饮商品、门店、价格、优惠、包装。若实际遇登录提示，请用户本人通过正常页面登录。遵守服务访问规则，不使用验证码绕过或账号凭据。
2. 查询商铺挂牌实际日期、转让组成、租期、押金及负责人报价；不把公开索引当成交。
3. 取得合法商家合同或脱敏账单后分开录入平台费、商家配送、活动承担、账期和退单；无合同仍为假设。不查询私密交易或未成年人个人轨迹。
4. 成人/家庭匿名调研、合规试营业、实际报价：以实测替换对应市场、成本、劳动、外卖证据输入。
5. 运行 python v3/models/build_startup_costs.py（若修改设备基表）、python v3/models/model_v3.py、python v3/models/skilled_cook_v3.py、python v3/models/validate_v3.py、python v3/reviews/independent_numeric_audit.py，然后用相同设计重新出PDF及HTML，独立验收。

本轮的全部结果、查证链接、照片授权和来源均在V3完整研究工程内。
